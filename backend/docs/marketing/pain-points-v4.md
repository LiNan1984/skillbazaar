## 一、买家痛点 TOP 10（购买 AI Skill 的用户）

### 痛点 1：不知道买什么 — 信息过载与选择困难

**现象**: 市场上有大量 Skill，但买家缺乏有效的推荐机制。面对几十上百个同类商品，难以判断哪个最适合自己的场景。搜索结果仅靠关键词匹配，无法理解用户的真实意图和上下文。

**SkillBazaar 对策**: BS 买卖助手（LangGraph AI Copilot）通过自然语言对话理解用户需求，主动推荐匹配商品，降低决策门槛。

**改进建议**:
- 增加「场景化推荐」引擎（例如："你是做电商运营的，推荐这些 Skill..."）
- 引入对比工具（Side-by-side 功能对比表）
- 增加「相似用户还买了」推荐

### 痛点 2：买之前无法验证效果 — 信任缺失

**现象**: 描述写得再好，用户担心买回来不 work。Skill 的"试错成本"包括金钱成本和集成时间成本。买家需要先看到实际运行效果才能做出购买决策。

**SkillBazaar 对策**: 内置沙盒执行引擎（虾塘），支持 Trial 模式试运行（限 512 tokens 输出），Code Skill 沙盒执行，Prompt Skill 在线演示。

**改进建议**:
- 每个商品详情页增加「一键试运行」入口（当前需要先购买/进入沙盒）
- 展示评估报告（eval_score + sample_output）在列表页预览
- 增加 Skill 录制演示视频功能

### 痛点 3：Skill 质量参差不齐 — 缺乏可信评分体系

**现象**: 平台上大量 Skill 质量差异巨大，但买家仅凭评分和下载量难以判断。部分 Skill 可能有注入攻击风险、过时的 Prompt、或者根本不 work。

**SkillBazaar 对策**: 静态检查 + LLM 烟雾测试双重评估（eval_service.py），注入模式检测，完整性校验（SHA-256 hash）。

**改进建议**:
- ✅ **评估分数在搜索结果中显性展示（v4.8 已完成）** — 星级/徽章
- 引入"平台认证"标签（通过评估阈值的高质量 Skill）
- 增加社区举报和人工复核机制
- 定期自动重新评估（cron job）

### 痛点 4：买了之后不会集成 — 使用门槛高

**现象**: 不同 Skill 的集成方式差异很大（Prompt 需调用 API、Code 需部署、SDK 需对接端点），买家缺乏技术能力完成集成。

**SkillBazaar 对策**: 提供 SKILL.md 标准格式导出（manifest_service.py），兼容 Agent Skills 规范；API Key 管理（CLI 访问）；MCP 协议支持。

**改进建议**:
- 为每个 Skill 提供「一键集成」代码片段（Python/JS/curl）
- 增加集成文档/教程
- 提供 SDK 封装（统一接口层，屏蔽底层差异）

### 痛点 5： Skill 过期/失效 — 维护责任不清

**现象**: 买了一个 Skill 后，卖家停止维护，LLM 版本更新导致 Skill 失效，买家不知道找谁。

**SkillBazaar 对策 (v4.1 已实现)**:
- ✅ **Skill Versioning** — SemVer 版本管理（skill_versions 表），卖家可为同一 Skill 发布多个版本
  - 自动创建 v1.0.0（产品发布时）
  - 版本历史追踪（changelog）
  - Rollback 机制（回滚到任一历史版本）
- ✅ **User Profiles** — 卖家展示页（GET /api/u/{username}），买家可查看卖家历史、关注卖家动态
- 卖家信息展示

**改进建议**:
- ~~增加 Skill 版本管理（semver）和更新通知~~ ✅ 已完成
- 建立「维护 SLA」承诺机制（卖家发布时声明维护周期）
- 买家可标记「已失效」，触发平台介入
- 自动通知已购用户新版本发布

### 痛点 6：买断制不适合试用 — 一次性付费决策压力大

**现象**: 全额购买一个未知效果的 Skill 风险太高。用户更愿意先低价试用再决定。

**SkillBazaar 对策**: Trial 模式（limited execution），Bounty 悬赏制（先描述需求再竞价），金币经济体系。

**改进建议**:
- 推广「试用到满意再买」的 Trial-to-Purchase 转化漏斗
- ✅ **分期/订阅模式（v4.7 开发中）** — 按月付费降低决策门槛
- 降低首次购买门槛（新手首单折扣）

### 痛点 7：安全顾虑 — 担心 Skill 包含恶意代码

**现象**: 上传的 Code Skill 可能包含恶意代码、数据泄露、后门。Prompt Skill 可能有 Prompt Injection 攻击。

**SkillBazaar 对策**: 虾塘加密（Fernet AES-256）存储代码，注入模式静态检测，沙盒隔离执行。

**改进建议**:
- 在评估报告中显式展示安全检测结果
- 引入第三方安全审计徽章
- 沙盒执行的网络隔离（禁止外传数据）

### 痛点 8： 搜索结果不精准 — 缺乏语义理解

**现象**: 当前搜索依赖关键词匹配，无法理解语义。搜"帮我做用户分析"可能匹配不到"数据分析Agent"。

**SkillBazaar 对策**: BS 买卖助手自然语言搜索 + 多意图路由。

**改进建议**:
- 引入向量搜索/语义搜索（Embedding 检索）
- 标签体系优化（自动标签推荐）
- 按运行时兼容性筛选（runtime filter 已有，需前端入口）

### 痛点 9：缺乏社区参考 — 孤立决策

**现象**: 没有看到其他用户的真实评价和使用案例，决策缺乏社会证明。

**SkillBazaar 对策**:
- ✅ **User Profiles (v4.1)** — 公开卖家/买家主页（bio、avatar、social_links），展示专业形象
- ✅ **Follow 系统 (v4.1)** — 关注卖家，获取动态更新；查看粉丝/关注列表
- ✅ **Achievements/Badges (v4.1)** — 成就系统，展示用户贡献（优质卖家、活跃买家等）
- ✅ **Reviews & Ratings (v4.13)** — 验证购买评价系统（verified purchase reviews）、有用/无用投票（helpful voting）、评分汇总展示

**改进建议**:
- ~~增加社区主页功能~~ ✅ 已完成（User Profiles）
- ~~评价系统增加「有用/无用」投票~~ ✅ 已完成（v4.13 Reviews & Ratings）
- 增加使用案例展示（Buyer Stories）
- 社区 Q&A 板块

### 痛点 10：价格体系不透明 — 不知道值不值

**现象**: Skill 定价差异巨大（¥1 到 ¥999），买家缺乏定价参考基准。不知道高价格是否对应高质量。

**SkillBazaar 对策**: 展示评分、下载量、销量等指标。动态定价模型已有定义。

**改进建议**:
- 增加「性价比评分」（性能/价格比）
- 同类商品价格区间可视化
- 历史价格趋势图

## 二、卖家痛点 TOP 10（创建/发布 AI Skill 的开发者）

### 痛点 1：曝光度低 — 好 Skill 无人问津

**现象**: 发布后几乎没有流量，平台的推荐/排序机制不透明，新品没有冷启动扶持。

**SkillBazaar 对策**: 平台 crawler 种子数据、分类浏览、BS 助手推荐。

**改进建议**:
- 新品流量扶持计划（前 7 天加权曝光）
- 卖家数据分析面板（曝光量、转化率、搜索排名）
- SEO 优化（每个 Skill 独立 URL + meta tags）

### 痛点 2：定价困难 — 不知道定多少合适

**现象**: 第一次发布 Skill，对市场接受度没有概念。定高了没人买，定低了亏本。

**SkillBazaar 对策**: 动态定价模型定义（fixed/dynamic/auction），评分和销量作为参考。

**改进建议**:
- 发布时提供「智能定价建议」（基于同类商品价格分布）
- 支持 A/B 定价测试
- 拍卖模式正式上线（卖家设置底价，买家竞价）

### 痛点 3：发布流程复杂 — 多步骤容易放弃

**现象**: 上传流程需要填写大量字段（名称、描述、分类、子分类、标签、预览内容、GitHub 地址、技能类型、文件上传），3 步表单容易流失。

**SkillBazaar 对策**: BS 买卖助手对话式发布（提取信息自动填充卡片）。

**改进建议**:
- 进一步简化发布流程（最少字段发布，后续补充）
- 增加「快速发布」模式（仅名称+价格+文件）
- 保存草稿功能

### 痛点 4：收入不稳定 — 一次性付费收入不可持续

**现象**: 买断制收入一次性的，后续没有被动收入。需要持续获新客才能维持收入。

**SkillBazaar 对策**: Cron 订阅制已有模型，Bounty 系统提供定制收入。

**改进建议**:
- ✅ **Skill 订阅模式（v4.7 开发中）** — 月费无限使用
- 收入分成透明化（平台费率公示）
- 提现流程自动化

### 痛点 5：买家集成遇到问题 — 售后负担重

**现象**: 买家买了 Skill 不会用，反复咨询卖家。卖家花大量时间在售后支持上，而非开发新 Skill。

**SkillBazaar 对策**: 内置文档（SKILL.md）、沙盒演示。

**改进建议**:
- 增加 Skill 自带的 FAQ / 常见问题
- 平台侧提供集成技术支持（文档 + 视频）
- 卖家可设置「集成服务」额外收费项

### 痛点 6：版权和盗版保护不足 — 辛苦做的东西被复制

**现象**: Code Skill 上传后被下载、反编译、免费分享。Prompt Skill 的文字内容容易被复制。

**SkillBazaar 对策**: 虾塘加密（Fernet AES-256），Hash 完整性校验。

**改进建议**:
- 添加水印/指纹（Skill 内容嵌入买家 ID 追踪）
- 法律条款模板（卖家可一键选择开源/闭源/自定义 License）
- 盗版举报快速处理通道

### 痛点 7：缺乏数据反馈 — 不知道如何优化

**现象**: 不知道用户怎么用 Skill 的，哪些功能受欢迎，哪些导致差评。优化没有数据支撑。

**SkillBazaar 对策**: 下载量、评分、销量统计。Execution 日志记录。

**改进建议**:
- 卖家数据面板（使用频率、用户画像、退出率）
- A/B 测试框架（同一 Skill 两个版本对比）
- 用户反馈聚合（评价关键词云）

### 痛点 8：竞品信息不透明 — 不知道市场趋势

**现象**: 不知道同类 Skill 的价格区间、销量趋势、功能差异。定价和功能设计缺乏市场依据。

**SkillBazaar 对策**: BS 助手市场分析功能，热门商品排序。

**改进建议**:
- 发布分类市场报告（月度/季度）
- 竞品对比工具（卖家可对比同类商品）
- 需求趋势看板（搜索热词变化）

### 痛点 9：版本管理混乱 — 更新导致混乱

**现象**: 更新 Skill 后，老用户用的是哪个版本？新用户又用哪个？License 如何绑定版本？

**SkillBazaar 对策**: Eval 版本号（eval_version），Skill 资产版本。

**改进建议**:
- 完整的 SemVer 版本管理
- 买家可查看/选择版本
- 自动通知已购用户更新

### 痛点 10：收款和税务 — 国际化卖家的合规难题

**现象**: 跨境收款、税务申报、发票管理等复杂问题阻碍开发者全球化销售。

**SkillBazaar 对策**: 当前无此机制。积分/金币体系。

**改进建议**:
- 接入 Stripe/PayPal 等国际化支付
- 自动生成税务报告
- 卖家可选择收款币种

## 四、SkillBazaar 独特优势（护城河）

### 1. 🦐 虾塘沙盒 — 独一无二的执行环境

全栈加密 + 隔离沙盒，买家可在购买前在安全环境中试运行任何 Skill。Code Skill 实际执行，Prompt Skill 真实 LLM 调用。这是当前市场上唯一提供此能力的平台。

### 2. 🤖 BS 买卖助手 — AI 驱动的交易 Copilot

LangGraph 多意图路由 + 对话式卡片交互。不是简单的搜索框，而是能理解需求、引导发布、分析市场的 AI 助手。大幅降低买家和卖家的操作门槛。

### 3. 📜 SKILL.md 标准化

与 Agent Skills 开源规范对齐，生成的 Skill.md 可直接被其他平台消费，形成格式壁垒。

### 4. 🔒 虾塘加密体系

Fernet AES-256 全栈加密，从上传到执行全程加密保护。Code Skill 的源代码在非沙盒环境不可见。

### 5. 🎯 四层品类覆盖

Agent + Skill + Cron + Workflow 全品类覆盖，买家一站式采购。Bounty 系统解决定制需求。形成完整的 AI 工作流市场。

### 6. 💰 金币经济 + 积分体系

内置虚拟货币（金币）+ 积分体系，降低用户付费心理门槛，形成平台内循环经济。

### 7. 📡 MCP 协议支持

支持 Model Context Protocol，Skill 可被任何 MCP 兼容客户端调用，极大扩展 Skill 的使用场景。

## 六、用户画像与需求矩阵

### Persona A: 「效率探索者」 — 中小团队运营/产品

- **特征**: 非技术背景，想用 AI 提升工作效率
- **需求**: 即买即用的 Skill，不需要技术集成
- **痛点**: 不知道选什么、不会集成、担心效果
- **我们的价值**: AI Copilot 推荐 + 沙盒试运行 + 一键购买

### Persona B: 「开发者创作者」 — 独立开发者/AI 工程师

- **特征**: 技术能力强，有自研 Skill/Agent
- **需求**: 简单发布、保护代码、获得收入
- **痛点**: 曝光度低、定价困难、盗版风险
- **我们的价值**: 虾塘加密保护 + 新流量扶持 + 数据面板
