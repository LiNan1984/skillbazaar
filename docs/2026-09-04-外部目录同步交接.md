## 3. 数据流

```
外部源 HTML/README/RSC
    → Crawler.fetch_list / parse_*
    → Crawler.fetch_detail → CrawlerResult
    → SyncService.sync_all
         ├─ incremental_save → backend/seeds/seed_<source>.json
         ├─ _write_committed_seed → backend/seed_<source>.json（合并同名）
         └─ persist_results → SQLite upsert (name + source_platform)
    → GET /api/products → 前端首页卡片
```

CLI 入口：

```bash
cd backend
python3 -m crawlers.sync_service              # 四源全量
python3 -m crawlers.sync_service agensi       # 单源
python3 -m crawlers.sync_service gate bitmart
```

HTTP：

```bash
curl -X POST http://127.0.0.1:8000/api/sync/start \
  -H 'Content-Type: application/json' \
  -d '{"sources":["gate","bitmart","agentskillshub","agensi"]}'

curl http://127.0.0.1:8000/api/sync/status
```

> `/api/sync/start` 当前 **无鉴权**，仅适合内网/本地；上线前应加 admin token。

## 4. 各源现状与解析策略

### 4.1 Gate（`Gate Skills Hub`）

- 源：`https://raw.githubusercontent.com/gate/gate-skills/master/README.md`
- 解析：按行匹配 `| [name](#anchor) | desc | \`ver\` | status |`，避免分隔行通过 `\s` 跨行吞掉第一行技能。
- 详情：拉 `skills/<name>/SKILL.md` 前 800 字作 `content_preview`。
- 定价：`COMPLEXITY_KEYWORDS` 中 **`installer` 必须排在 `simple` 前**，否则 `gate-mcp-installer` 会被标成付费（应为 0）。

### 4.2 BitMart（`BitMart Skills`）

- 源：BitMart skills README（结构同 Gate）。
- 当前 3 条：spot / futures / **wallet-ai**（新增）。
- 已删除「解析失败就写死两条」的假数据回退；解析 0 条直接 `RuntimeError`。

### 4.3 AgentSkillsHub（`AgentSkillsHub`）

- 主源：`https://agentskillshub.dev/openclaw/skills/` 的 Next.js RSC flight 里的 skills 数组。
- 字段含：`name/slug/description/stars/install_count/securityGrade/source_url` 等。
- 默认只落库 **热度 Top 200**（`MAX_SKILLS = 200`），避免一次灌入近 3000 条。
- **禁止**用 sitemap 仅有 slug、无描述的结果当成功爬取去覆盖种子（会写成「某某是一个 AI Agent 辅助工具…」类合成文案）。

### 4.4 Agensi（`Agensi`）— 踩坑最多

| 规则 | 说明 |
|------|------|
| 列表只认 href | 仅 `href="/skills/<slug>"`（或绝对 URL）可进列表 |
| 禁止 UI 造名 | 「Browse Free Skills」「Agensi Free Skill Explorer」曾被旧正则切成 `rowse` / `gensi` 并入库（描述变成 `"S"`） |
| 价格以详情为准 | 读 `application/ld+json` 里 `offers.price`（USD）；`×5` 转金币 |
| 列表不要默认 Free | `price_str` 空着，等详情；否则会把付费技能刷成 0 |
| 404 丢弃 | `fetch_detail` 非 200 或缺少 Product/描述信号 → `return None`，不 persist |
| 已清理 | DB + `seed_agensi.json` 中已删除 `rowse` / `gensi` |

付费样例（刷新后）：

- `1-klick-magnet-website` → $19 → **95** coins  
- `design-philosophy` → $9.99 → **50**  
- `cinematic-sites` → $12 → **60**

## 7. 运维 / 排障清单

1. **API 看不到新商品**  
   确认 Sync 写的是 `backend/data/skillbazaar.db`，不是根目录那份。

2. **某源 crawled 0**  
   看 stdout `[Sync] ERROR: ...` 或 `Source status`；不要把空结果当成功。可 `POST /api/sync/reload-seeds` 仅补「库中缺失」行（不更新已有字段）。

3. **Agensi 又出现短奇怪名**  
   检查是否又引入了「从 Free/$ 文本创建新 name」的逻辑；先 `DELETE ... WHERE name IN ('rowse','gensi')`。

4. **Gate 安装器变付费**  
   确认 `COMPLEXITY_KEYWORDS` 中 `installer` 优先于 `simple`。

5. **ASH 描述变模板句**  
   说明 RSC 解析失败却走了弱回退；当前实现应对此 `RuntimeError`，保持旧种子。
